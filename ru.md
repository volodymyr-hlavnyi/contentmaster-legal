# Политика конфиденциальности — @KontentMasterBot

**Дата вступления в силу:** 26/02/2026

Если вы не согласны с данной Политикой, пожалуйста, не используйте Сервис.

## 2. Какие данные мы собираем

### 2.1 Данные Telegram-аккаунта
При взаимодействии с ботом мы можем обрабатывать:
- Telegram ID пользователя
- Telegram username (если доступен)
- выбранный язык
- данные об использовании (например, количество бесплатных генераций и приобретённых кредитов)

### 2.2 Загружаемые изображения
Вы можете загружать изображения для создания визуализаций.

Изображения обрабатываются исключительно для предоставления функциональности Сервиса.

Мы не осуществляем намеренный сбор чувствительных персональных данных.  
Пожалуйста, не загружайте:
- документы, удостоверяющие личность
- конфиденциальную или личную информацию
- материалы, защищённые авторским правом, без соответствующего разрешения

### 2.3 Данные, связанные с оплатой
При покупке кредитов:

Платежи обрабатываются Telegram и/или соответствующими платёжными провайдерами.

Мы не храним данные банковских карт.

Мы можем хранить:
- статус подтверждения покупки
- баланс кредитов
- идентификаторы транзакций, предоставленные Telegram

## 3. Как мы используем информацию

Мы используем собранную информацию для:
- предоставления сервиса генерации изображений
- управления кредитами и лимитами пользователей
- улучшения качества работы сервиса
- предотвращения злоупотреблений и обеспечения безопасности

Мы не используем ваши данные в рекламных целях.

## 4. Обработка и хранение изображений

Изображения обрабатываются исключительно для создания запрошенных визуализаций.

Мы не продаём ваши изображения.

Мы не используем изображения для установления личности.

В технических целях мы можем хранить:
- Telegram file_id
- метаданные генерации
- текстовые промпты, необходимые для воспроизведения контекста генерации

Мы не осуществляем намеренного долгосрочного хранения исходных файлов изображений сверх необходимого для функционирования Сервиса.
